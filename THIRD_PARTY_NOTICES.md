# Third-party notices

This repository aggregates skills from multiple upstream projects and individual
contributors. No repository-wide license overrides the terms of an included skill.

For each skill, consult in this order:

1. a `LICENSE`, `LICENSE.txt`, or similarly named file inside the skill directory;
2. the `license`, `source`, and `source_repo` fields in `SKILL.md`;
3. the linked upstream repository when local metadata is incomplete.

Primary imported collections:

- Anthropic Skills: <https://github.com/anthropics/skills>
- OpenAI Skills: <https://github.com/openai/skills>
- Agentic Awesome Skills: <https://github.com/sickn33/agentic-awesome-skills>

The original Anthropic third-party notice is retained locally at
`sources/anthropic-skills/THIRD_PARTY_NOTICES.md` for audit purposes.
