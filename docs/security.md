# Security model

This repository stores instructions and executable helpers from many independent
sources. Catalog inclusion is not a security certification.

## Before using a skill

- Read the complete `SKILL.md` and any script that would execute.
- Check the `risk` label and the actual requested side effects.
- Verify commands, package names, URLs, and credential handling independently.
- Use an isolated workspace for unfamiliar or offensive-security content.
- Require explicit authorization before deletion, deployment, publishing, account
  changes, purchases, credential use, or communication with third parties.
- Use offensive skills only on systems you own or are authorized to test.

## Repository guarantees

The local validator checks structure and references but does not execute scripts,
prove factual correctness, scan every dependency, or certify an upstream source.
Raw repositories under `sources/` are never runtime dependencies and should not be
executed without review.

## Reporting a problem

Quarantine a harmful skill by opening a focused change that preserves evidence,
documents the reason, and updates the catalog. Do not silently replace provenance
or remove license notices.
